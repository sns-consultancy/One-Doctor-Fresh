# OneDoctor (Vite + React + Netlify)

A privacy-minded health companion: symptom tools, medical note summarizer, records, camera HR, and AI helpers.  
Frontend: **Vite + React**. Server logic: **Netlify Functions**.

---

## Quick Start

```bash
# 1) Install deps
npm i

# 2) Run locally
npm run dev

# 3) Build
npm run build
